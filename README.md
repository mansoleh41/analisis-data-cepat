# analisis-data-cepat

Satu perintah untuk memahami file CSV: ukuran, tipe kolom, nilai kosong, duplikat, statistik, dan nilai teratas.

```bash
pip install -r requirements.txt
python profil_csv.py contoh/penjualan.csv
python profil_csv.py contoh/penjualan.csv --md laporan.md
```
Hasil berupa Markdown yang bisa ditempel ke laporan atau diberikan ke Claude untuk analisis lanjutan.
